# Spectro-Spatial Survey Fusion — paper code

Research artifact accompanying **Spectro-Spatial Survey Fusion**, by Georgios N. Vassilakis, Miles Cranmer, and Vasily Belokurov.

This repository preserves an experimental snapshot of the implementation used for the paper. It contains the model, SDSS training code, paper configurations, supporting metadata, selected evaluation tools, and numerical summaries. No ongoing maintenance is planned.

Raw survey observations, prepared caches, and fitted checkpoints are not included. The complete HSC/DESI analysis and figure-generation workflows are also outside this release.
